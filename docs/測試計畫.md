# MovieIn 電影推薦系統 - 測試計畫

## 1. 測試目的

規劃 MovieIn 電影推薦系統的整合與測試各項流程及所需準備工作，說明系統測試所需使用的測試工具及配置的測試環境，確保系統在各項功能需求下能夠穩定運作並達成性能目標。

---

## 2. 重點範圍

測試「MovieIn 電影推薦系統」各項開發功能與測試介面，驗證測試結果是否顯示正常及順利運作。測試涵蓋範圍包括：

### 2.1 核心功能測試
- **智能推薦系統**：Feature Matching + Embedding 雙引擎推薦
- **特徵提取服務**：Mood Label 映射、Keyword 匹配、自然語言推斷
- **使用者偏好管理**：Quiz 測驗、喜好設定、歷史記錄
- **電影資料查詢**：搜尋、篩選、詳細資訊顯示
- **系統整合**：前後端 API 通訊、資料庫連線、外部服務整合

### 2.2 測試功能模組
- **UC-01**: 使用者註冊與登入
- **UC-02**: 電影推薦查詢與結果顯示
- **UC-03**: 使用者偏好測驗（Quiz）
- **UC-04**: 電影詳細資訊查看
- **UC-05**: 喜好清單管理
- **UC-06**: 推薦系統參數調整

## 3. 測試方法

### 3.1 單元測試（Unit Testing）
- **測試方法**：白箱測試
- **測試工具**：pytest + pytest-cov
- **涵蓋範圍**：
  - 推薦演算法核心邏輯 (`simple_recommend.py`)
  - 特徵提取服務 (`enhanced_feature_extraction.py`)
  - 資料庫模型與查詢 (`models/`, `db/`)
  - API 端點處理 (`routers/`)

### 3.2 整合測試（Integration Testing）
- **測試方法**：灰箱測試
- **測試範圍**：結合測試內部邏輯與外部行為，驗證各模組間的協作
- **測試重點**：
  - API 端點與資料庫整合
  - 推薦引擎與特徵提取服務整合
  - 前後端 API 通訊整合
  - 外部服務（OpenAI Embedding、TMDB）整合

在這種測試中，我們不僅分析程式的輸入和輸出，還深入檢視和驗證程式碼的內部結構，包括條件分支和邊界情況。這種方式能更全面地覆蓋程式碼，確保其在各種情境下都能穩定運作。

### 3.3 端到端測試（E2E Testing）
- **測試方法**：黑箱測試
- **測試範圍**：模擬真實使用者操作流程
- **測試工具**：aiohttp (異步 HTTP 測試)

### 3.4 壓力測試（Stress Testing）
- **測試方法**：性能負載測試
- **測試目標**：驗證系統在高併發下的穩定性與響應時間
- **測試階段**：4 RPS → 6 RPS → 8 RPS → 10 RPS → 15 RPS → 20 RPS → 50 RPS
- **成功標準**：
  - 50 RPS 下成功率 ≥ 95%
  - P99 延遲 < 1,000ms
  - 平均延遲 < 500ms

## 4. 測試環境

### 4.1 伺服器機器規格（部署環境）

**方案一：Render.com 雲端部署**
- **作業系統**：Linux (Container)
- **服務類型**：Web Service
- **區域**：Singapore
- **資料庫**：PostgreSQL (Neon Cloud)
- **後端 URL**：https://moviein-api.onrender.com
- **前端 URL**：https://moviein.vercel.app (Vercel 部署)

**方案二：本地開發環境**
- **作業系統**：Windows 10 / 11
- **Python 版本**：3.10+
- **資料庫**：PostgreSQL 13+ (本地或 Neon Cloud)
- **後端**：uvicorn (127.0.0.1:8000)
- **前端**：Next.js Dev Server (localhost:3000)

### 4.2 測試客戶端機器規格

**開發測試環境**
- **作業系統**：Windows 10 / 11
- **中央處理器**：Intel Core i5 以上 (建議 i7-10750H @2.60GHz 或更高)
- **記憶體**：8 GB 以上 (建議 16 GB)
- **網路環境**：寬頻網路 (建議 100 Mbps 以上)
- **Python 版本**：3.10+
- **Node.js 版本**：18.0+

**CI/CD 測試環境**
- **平台**：GitHub Actions (待實作)
- **作業系統**：Ubuntu Latest
- **自動化測試**：每次 Pull Request 觸發

### 4.4 測試工具

| 工具 | 版本 | 用途 | 說明 |
|------|------|------|------|
| **pytest** | 7.0+ | 單元測試、整合測試 | Python 測試框架，支援標記、覆蓋率報告 |
| **pytest-cov** | Latest | 程式碼覆蓋率 | 測量測試覆蓋率並生成報告 |
| **pytest-asyncio** | Latest | 異步測試 | 支援 async/await 測試 |
| **aiohttp** | Latest | 壓力測試、E2E 測試 | 異步 HTTP 客戶端 |
| **Stress Test Script** | Custom | 系統壓力測試 | `backend/scripts/stress_test.py` |
| **Apache JMeter** | 5.0+ | GUI 壓力測試（可選） | 視覺化壓力測試工具 |

### 4.5 測試執行指令

```powershell
# 單元測試
cd backend
pytest tests/unit -v --cov=app/services --cov-report=html

# 整合測試
pytest tests/integration -v

# E2E 測試
pytest tests/e2e -v

# 壓力測試（快速模式）
python scripts/stress_test.py quick

# 壓力測試（完整模式）
python scripts/stress_test.py

# 性能診斷
python scripts/diagnose_performance.py
```
