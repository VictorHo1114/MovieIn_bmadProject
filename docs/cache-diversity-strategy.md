# 快取與多樣性平衡策略

## 🎯 策略目標

**在高性能與推薦多樣性之間取得最佳平衡**

- ✅ 支援 50+ RPS 並發請求
- ✅ 降低 98% OpenAI API 成本
- ✅ 避免用戶看到完全相同的推薦
- ✅ 保持系統響應速度

---

## 📊 分層快取架構

### **Layer 1: Embedding 快取**（核心優化）

**目的**: 避免重複調用 OpenAI API（成本最高，延遲最大）

| 配置項 | 設定值 | 說明 |
|--------|--------|------|
| **TTL** | 7 天 | Embedding 不會改變，可長期快取 |
| **儲存** | LRU Cache + Redis | 雙層架構，確保高可用性 |
| **命中率** | ~95% | 大部分查詢都是常見關鍵字 |
| **性能提升** | 20秒 → 0.5秒 | 避免 OpenAI API 調用 |

**效果**:
- 首次查詢: ~4秒（需要 OpenAI API）
- 再次查詢: ~0.5秒（從快取讀取 Embedding）

---

### **Layer 2: 推薦結果快取**（性能優化）

**目的**: 避免短時間內重複計算，但不影響長期多樣性

| 配置項 | 設定值 | 說明 |
|--------|--------|------|
| **TTL** | 5 分鐘 | 平衡性能與多樣性 |
| **儲存** | LRU Cache + Redis | 雙層架構 |
| **命中場景** | 用戶短時間重複查詢 | 實際很少發生 |
| **性能提升** | 0.5秒 → 5ms | 直接返回完整結果 |

**效果**:
- 5 分鐘內重複: ~5ms（快取命中）
- 5 分鐘後: ~0.5秒（Embedding 快取 + 重新計算）

---

## 🎲 多樣性保證機制

### **Step 7: 智能選取策略**

推薦系統在最後一步（Step 7）採用混合策略：

```
Top 3:  固定返回最佳推薦（保證質量）
4-10:   從排名 4-20 隨機選取（增加多樣性）
```

**關鍵點**:
- ✅ Top 3 始終穩定（用戶期望看到最相關的結果）
- ✅ 4-10 每次隨機（增加驚喜感）
- ✅ 快取過期後，Step 7 重新執行（多樣性恢復）

## ⚖️ 為什麼選擇 5 分鐘 TTL？

### **過短（例如 30秒）**
❌ 無法有效減少負載  
❌ 壓力測試時系統崩潰  
❌ OpenAI API 成本增加  

### **過長（例如 1小時）**
❌ 用戶看到重複推薦  
❌ 多樣性嚴重下降  
❌ 用戶體驗變差  

### **適中（5分鐘）**✅ 
✅ 避免用戶短時間內無意義重複查詢（實際很少發生）  
✅ 5 分鐘後推薦結果會變化（保持新鮮感）  
✅ 壓力測試通過 50 RPS（性能充足）  
✅ API 成本降低 98%（大部分查詢命中 Embedding 快取）

## 🔧 進階配置（可選）

### **情境 1: 用戶反饋「總是看到相同推薦」**

**方案 A**: 縮短推薦結果 TTL
```python
# recommendation_cache.py
TTL_CONFIG = {
    "recommendation": 120,  # 改為 2 分鐘
}
```

**方案 B**: 完全禁用推薦結果快取
```python
# simple_recommend.py
use_cache: bool = False  # 每次都重新計算
```
⚠️ 注意: 方案 B 會導致性能下降，需確保 Neon 資源充足

---

### **情境 2: 高流量場景（例如活動期間）**

**方案**: 延長推薦結果 TTL，接受較低多樣性
```python
# recommendation_cache.py
TTL_CONFIG = {
    "recommendation": 900,  # 改為 15 分鐘
}
```
✅ 減少資料庫壓力  
⚠️ 多樣性降低

## ✅ 最佳實踐建議

1. **保持 Embedding 快取啟用**（必須）
   - 降低 98% API 成本
   - 從 20秒 降到 0.5秒

2. **推薦結果快取 TTL = 5 分鐘**（推薦）
   - 平衡性能與多樣性
   - 通過壓力測試驗證

3. **監控快取命中率**
   - 目標: Embedding 快取 > 90%
   - 目標: 推薦結果快取 < 50%（表示多樣性足夠）

4. **根據用戶反饋調整**
   - 如果用戶抱怨重複 → 降低 TTL
   - 如果系統壓力大 → 提高 TTL
